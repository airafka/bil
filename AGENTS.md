# Рабочая копия для доработок

Сначала читать COPY_INFO.md, затем HANDOFF.md, README.md, BACKEND_ALIGNMENT.md и DESIGN.md.
Все новые изменения выполнять в этом каталоге bil-next. Исходный проект bil и контейнеры billing-* сохранять без изменений. Использовать только compose-проект billing-next, frontend3001/backend8081/БД5433. Не запускать исторические scripts без проверки жёстко заданных путей, портов и имён контейнеров. Не повторять одноразовые скрипты. Перед миграциями/изменениями данных — свежая копия БД; изменяющие тесты — только отдельная тестовая БД. Сохранять незакоммиченные изменения, не делать commit/push без запроса.

Перед изменениями frontend читать [FRONTEND_STANDARD.md](FRONTEND_STANDARD.md). Использовать общие компоненты/токены; таблицы сохраняют колонки и иерархию с горизонтальной прокруткой. Не добавлять локальные размеры или необязательные фильтры.
