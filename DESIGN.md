## Оформление интерфейса

Общие стили MVP адаптированы по экранам реестра `6336:19827`, создания
`5911:60712` и просмотра `1838:515322` на странице «ЖД, Контейнерная площадка».
Поля, статусы и действия остаются из текущей модели MVP.

- Светлая рабочая область, компактная боковая навигация с возможностью раскрытия.
- Вкладки на светлой подложке, активная вкладка — белая с тонкой рамкой.
- Формы: две колонки на широком экране, подписи слева; на узком экране — одна колонка.
- Просмотр: текстовые значения вместо заблокированных полей, группы отделены линией.
- Реестры: светло-синяя шапка, компактные строки, тонкие горизонтальные разделители.
- Статусы различаются текстом, цветом и маркером; действия доступны с клавиатуры.

Основные правила находятся в `frontend/src/design-system.css`, сетка ввода —
в `frontend/src/form-controls.css`. Цвета полей используют существующие токены UI kit.

Вкладки состава ЖД-поставки сверены с экранами создания: вагоны `5911:61274`,
КТК `6004:226293`, грузы `5911:61629`; просмотра: вагоны `1838:516530`,
КТК `9869:57541`, грузы `1838:517058`.
Общий компонент `WaybillCompositionTable` показывает одну таблицу с раскрываемыми
группами накладных; для КТК — дополнительный уровень вагонов. В создании данные
из накладных показаны на светлой подложке, в просмотре — обычным текстом.
Состав выбранных накладных не редактируется внутри заявки. API сгруппированных
накладных дополнен `railwayCarriages` с вложенными КТК; схема БД не менялась.

Просмотр состава уточнён по четырём скриншотам Figma: накладные — плоская таблица; вагоны/груз — группы по накладным; КТК — накладная → вагон → КТК. Номер группы занимает общую ячейку слева (rowSpan). Шапка голубая, высота строк 42px, тонкие границы и отступы вложенности; повторные заголовки и маршруты убраны. Используются реальные поля MVP, без фиктивных данных ЭТРАН, ЗПУ, собственников и классов опасности. Один груз на накладную сохранён.

Над табличными списками удалены поиск, фильтры и дублирующие подписи реестров/счётчики. Сохранены названия страниц, заголовки столбцов, пагинация, действия и обязательные реквизиты форм создания документов (включая клиент/договор/период счёта).

Все вкладки используют общую подложку #f2f4f7, высоту 40px, текст 16px; активная вкладка белая с рамкой #d0d5dd и лёгкой тенью. На узком экране — горизонтальная прокрутка без переноса подписей. Повторные заголовки состава и подписи количества над таблицами убраны; названия вложенных вагонов/накладных, поля ввода и действия сохранены.
