# UX-аудит MVP · 28 октября 2026

Экспертная оценка интерфейса и кода, без интервью и пользовательского тестирования. Сохранены цвета, поля и табличный характер исходного Figma/UI kit.

## Найденные проблемы и изменения

| Проблема | Решение |
| --- | --- |
| В реестрах заявок нет способа найти клиента или договор | Серверный поиск по номеру, клиенту, договору и статусу во всех трёх реестрах; поиск учитывается в количестве и пагинации |
| Одинаковое сообщение для пустой базы и пустой выдачи | Контекстные сообщения с предложением изменить фильтры |
| Нельзя повторить неудачную загрузку | Повторная загрузка реестров заявок и начислений |
| Навигация теряет подписи на узких экранах | Подписи на планшете и телефоне, прокрутка мобильного меню, группы разделов на компьютере |
| Состояние меню сбрасывается | Сохранение свёрнутого/раскрытого состояния локально |
| Длинная карточка услуги требует много прокрутки | Переходы к поставке, вывозам, возвратам и начислениям со счётчиками |
| Непонятно, сохранены ли изменения | Видимые сообщения после сохранения комплексной услуги/тарифа; сохранение неизменённой тары недоступно |
| Сообщение об успешном сохранении тары красное | Зелёный цвет успешного состояния |
| Плотные таблицы и теряющиеся заголовки | Единый ритм строк, закреплённые заголовки внутри прокручиваемых таблиц |
| Формы тесные на планшетах | Одна колонка форм на средних экранах; подпись над полем на телефонах |
| Фильтры накладных не отправляются через Enter | Семантическая форма и сброс ошибки при очистке |
| Нет поиска в справочнике услуг и рейсах | Поиск по наименованию услуги и номеру рейса по загруженному списку |
| Неизвестная ссылка незаметно перенаправляет | Явная страница «не найдено» с возвратом в реестр |

## Границы

Бизнес-процессы, расчёты, статусы, данные и миграции не изменялись. Добавлены только параметры чтения query/status в API реестров. Поиск по заявкам по всей базе; КТК, рейсы и комплексные услуги сохраняют существующие API списков.

Следующий этап после наблюдения за работой операторов: сохранённые фильтры, расширенный поиск по КТК в заявках, единый механизм защиты несохранённых многошаговых форм. Эти возможности в текущие изменения не включены.
